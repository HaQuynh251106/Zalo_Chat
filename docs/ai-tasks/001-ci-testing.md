# Task 001: CI/CD and Testing Baseline


## Goal
Add a reliable CI/testing baseline for the existing Lumo Phase 0 MVP.

## Requirements
- Add GitHub Actions workflow.
- Run backend tests.
- Run Flutter tests if Flutter app exists.
- Add build/lint checks where available.
- Do not change product behavior.
- Do not refactor unrelated code.
- Document local test commands.

## Out of Scope
- Auth changes.
- Chat features.
- Media migration.
- Push worker.
- Database schema changes.

## Done When
- CI workflow exists.
- Local test commands are documented.
- Existing tests pass or known failures are documented.
